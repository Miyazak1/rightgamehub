# `@mooyu/courseware-domain-packs`

中国高中数学、物理、化学首批结构化课件领域模块。模块只包含确定性状态、命令与可观察模型，不包含页面样式、宿主 API 或网络请求。

- 数学：二次函数系数、开口、宽窄、采样点与参考曲线。
- 物理：恒力小车的质量、力、时间、位移、速度与受控实验记录。
- 化学：`N₂O₄ ⇌ 2NO₂` 的反应商、平衡常数、平衡组成和条件改变。
- 通用：工作台模式/面板状态，测量记录/比较仪器。
- 挑战：数学命中目标、物理补给车入区、化学安全配比，均只读取对应 Domain 的权威状态。
- 学习旅程：检查点、完成度与提示状态；嵌入：宿主连接、语言和导出计数的隔离状态。

正式课件通过固定 Builder 将所选实现复制为课件内单文件 ESM，并由模块锁固定 SHA-256；运行时不从该工作区包或远程注册表临时取代码。三套参考课件都以六个根模块发布：`domain + instrument + component + challenge + journey + embed`；未来可按课件需要增删，而不是复制一套新的运行时。
