# P0 邀请内测闭环

日期：2026-09-29 · 当前增量：P0.1 完成，P0.2 本地安全闭环完成，P0.3 本地治理闭环完成

## P0.1 已完成

- `0014_library_and_daily_results.sql` 增加账号级游戏库、最近游玩和“猜百科”完成成绩。
- 作品详情的“加入游戏库”已接入真实 API，支持取消收藏。
- 游戏启动会记录最近游玩与累计次数；游戏库同时展示已收藏和最近游玩。
- GameHub 官方“猜百科”进入真实匿名目录，不再仅存在于 `?demo=1`。
- 每日题由 API 按 `Asia/Shanghai` 自然日统一选择，客户端不再独立决定日期与题目。
- 登录用户通关后会保存题目、猜字数、用时和提示次数。
- OpenAPI、客户端、Harness bundle 与真实 PostgreSQL 开发实例同步升级。

## P0.2 已完成的基础防护

- 上传头像除文件体积与格式签名外，新增 PNG、JPEG、GIF、WebP 实际宽高与总像素校验。
- 头像最大尺寸限制为 `1024 × 1024`、最大总像素为 `1,048,576`；超限会以 `AVATAR_DIMENSIONS_INVALID` 拒绝。
- 创作者上传流程把并未实际执行的“安全扫描”改为“安全规则检查”，避免给用户错误的安全承诺。
- 个人设置页新增已登录设备列表，可逐台撤销、退出其他设备或退出全部设备；服务端同步吊销对应访问令牌与刷新令牌。
- GIF、APNG 与动态 WebP 改为按容器结构解析，最多 60 帧、总时长最多 15 秒；截断、尾随数据和帧数声明不一致会被拒绝。
- 上传图片再经过受限像素解码并统一重编码为去元数据 WebP；动态头像同时生成静态 WebP，系统“减少动态效果”时自动使用。
- 新头像的动态文件和静态降级图已迁出 PostgreSQL，进入受约束的内容寻址私有存储；数据库只保存对象键、哈希和尺寸/帧数元数据。覆盖头像或切换系统头像会回收旧对象，旧数据库内头像仍可兼容读取。
- Harness 通过 Git Credential Manager 接入宿主系统凭据库，访问令牌和刷新令牌不再写入普通文件；宿主凭据库不可用或写入失败时会明确降级为仅内存会话。
- 设备会话新增最近活动时间，并以五分钟窗口节流数据库写入；个人设置页同时展示最近活动与首次登录时间。
