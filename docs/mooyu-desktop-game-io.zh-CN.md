# 桌面多人、分享与文件导出

本轮只修改本地客户端；没有提交、推送、部署、修改正式 API 或更新远程隔离实例。业务继续使用网页版现有 API，未增加另一套账号或业务数据库。

## 多人连接

房间、邀请、准备、开始、对局及回放通过固定 API 方法桥接；字段按现有协议校验，房间和对局必须属于已经读取并与当前运行作品绑定的模式。管理员、发布、模型接口不在白名单中。

主进程持有真实实时票据和 WebSocket。只接受当前 API 同来源的 `/v1/realtime`（HTTPS 对应 WSS，回环 HTTP 对应 WS），拒绝凭据、额外查询、跳转和任意远端地址。票据和账号令牌不会发给 renderer 或游戏 iframe。

renderer 的 IPC socket 复用网页版 `createMultiplayerSession`，保留心跳、重连、房间恢复及对局序列同步。主进程再次校验协议、消息大小、速率和作品资源范围。窗口关闭、主框架导航或账号变化会退役连接，游戏子框架的 hash 导航和重载不会清理主页面连接。打开请求的微任务尚未执行时关闭，不再发送打开请求；迟到票据和代理解析结果不能重建旧连接。普通网络断开仍可重连。主界面 CSP 和任意联网权限没有放宽。

实时连接使用 HTTP 所在 Chromium 会话的代理解析结果，支持 DIRECT、HTTP(S) CONNECT 和 SOCKS。采用解析结果的首个路由，代理失败不会静默退回直连；需要代理认证的环境尚未验收。解析前移除实时票据查询参数，代理 agent 随连接释放。目标来源和路径、禁止跳转、证书信任链及目标主机名校验均保留；没有关闭 TLS 验证。

## 分享链接

复用 `createGameShare`、`getGameShare`、`/s/:code` 和已有 SDK。创建依赖当前运行版本获准的 shareLinks 会话；标题与 JSON 仍受 16 KiB 等既有约束。接收端按分享记录中的作品和版本加载，版本错配拒绝。系统浏览器链接自动唤起桌面的操作系统协议注册不属于本轮范围。

桌面 business IPC 的封包上限为 32 KiB，操作自身仍有严格字段和独立限额；账号操作保持 4 KiB。这样合法的分享与最长 8192 步回放不再被账号封包限制误拦。没有开放通用 HTTP 或任意 JSON 透传。

## 文件导出

沿用网页版游戏的“保存游戏文件”确认，再显示 Windows 原生保存对话框。仅接受既有协议允许的 PNG（2 MiB）和 JSON（256 KiB），检查文件名、PNG 结构/CRC、JSON 结构及扩展名。路径只由原生对话框提供，不由 renderer 或 iframe 指定，也不回传给它们。

主进程在选择前后重新验证当前发布版本和 fileExport 能力；账号变化或取消后不写入。先写同目录独占临时文件并刷新，再替换目标；取消或失败会清理临时文件。没有开放任意下载、路径读写或执行文件。存档管理器既有的备份下载另有 1.5 MB 格式和权限语义，未把它混入游戏 PNG/JSON 导出通道。

## 本地验证

`node --test tests/platform/desktop-game-io.test.mjs` 使用全新的回环 HTTP/WebSocket 契约服务和临时目录，覆盖：

- SDK 房间操作、连接、重连恢复、对局同步、指令与退出停止重连。
- 跨游戏资源、未知或过大协议消息、错误端点、迟到票据拒绝。
- 大于 4 KiB 的合法分享、原版本接收及错版本拒绝。
- PNG/JSON 保存、路径/格式拒绝、取消及账号变化保留原文件。

`node scripts/verify-desktop-clean.mjs` 验证干净导出目录的全部回归和桌面构建，不连接正式服务。旧 D1、论文实现与测试凭据保持排除。

`node --test tests/platform/desktop-game-io-lifecycle.test.mjs` 补充 5 项导航、微任务关闭和代理回归，包括代理解析期间退役、不可信证书及错误主机名拒绝。`node scripts/verify-desktop-game-io-lifecycle.mjs` 使用干净目录构建和隐藏的真实 Electron 窗口，验证子框架导航/重载、主框架历史/重载，以及必须通过本机 CONNECT 代理的 WSS；全部端点均为本机回环，不使用正式 profile。
