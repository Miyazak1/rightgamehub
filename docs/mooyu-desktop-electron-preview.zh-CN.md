# 墨鱼工坊 Electron 共享界面预览

日期：2026-11-01。对应[完整客户端方案](./mooyu-desktop-full-client-plan.zh-CN.md)的阶段 A 及阶段 B 的本地账号验证。本地预览与邮箱会话的隔离验证已实现，远程服务器业务、原生执行接入与发行仍按后续阶段推进。

## 已实现

Electron 外壳直接导入共享 App、业务组件和 styles.css，没有复制发现页、工具或创作者界面。桌面宿主标记为 Windows，保留网页版的导航、品牌、中文/英文与深色、浅色、高对比主题。标题栏与共享导航合为一行，原生窗口按钮随主题变化；本地预览说明收为小标识和说明弹窗。目录中的唯一作品是明确标注的平台自有本地交互样本。

主窗口加载 `mooyu-app://client` 下的本地构建。协议提供正确的 JS、Worker 和资源类型，支持 SPA 深链回退；丢失的 JS/WASM/Worker 不回退为 HTML。启用 sandbox、contextIsolation、webSecurity，关闭 Node 与 webview 集成。preload 提供无凭据的预览环境信息、固定枚举的窗口操作与账号操作，不暴露通用 IPC、任意 HTTP、文件或命令执行；每次调用核对主窗口、顶层 frame 和来源。账号令牌只在主进程及 DPAPI 加密库中，不返回 renderer。

renderer 仅允许本地 UI 与由进程启动的随机 loopback 游戏样本来源；外部导航、新窗口、权限和下载默认拒绝。显式配置本地账号 API 时，主进程仅通过固定账号方法连接该 loopback origin，拒绝远程地址和跳转，不向 renderer 开放网络代理。游戏沿用现有 PlayerCore 与 sandbox iframe，不改变生产 release 来源规则。游戏 frame 中没有 Node、process 或桌面桥，不能访问父页面 DOM。

产品启动入口、测试入口和本地启动器分别验证。Electron 的 default-app 加载器不保证 `require.main` 指向传入的 CJS 文件，产品入口改用实际入口路径判断，避免“导入测试通过但双击无窗口”。用户数据和 Chromium 缓存在 ready 事件前设置到隔离目录；重复启动采用单实例锁恢复现有窗口。

## 本轮结果

| 检查 | 结果与证据范围 |
| --- | --- |
| 共享页面 | 发现、学习、五个官方工具、独立变化雷达页面均挂载；服务器功能保持未接通，不伪造在线成功 |
| 样式与操作 | 可见窗口实查中文导航、工具目录、浅色/深色/高对比主题切换；实际鼠标进入游戏并把计数从 0 增到 1 |
| 路由 | 共用导航进入工具页、历史返回、直接深链和刷新通过 |
| 隔离 | 主页面无 Node，桥仅环境信息及受限窗口/账号操作，不返回令牌；iframe 无桥和 Node，不能访问父 DOM；外部 fetch 被 CSP/网络策略拒绝 |
| 网页游戏 | 实际 PlayerCore 创建并运行自有 iframe 样本，脚本和点击均工作；不等于所有第三方游戏已经兼容 |
| PDF | 生成文本 PDF 通过共享阅读器的 PDF.js Worker 渲染与提取；额外导入现有 15 页 arXiv PDF，页数、标题、正文和画布均核对通过 |
| OCR | 扫描 PDF 经实际 Tesseract Worker/WASM 与本地语言资源识别出 `MOOYU OCR TEST 12345`；中英语言资源均加载，但本轮不宣称中文识别准确率或复杂版面能力已验收 |
| 本地存储 | localStorage、IndexedDB 写入，并在完整 Electron 进程退出重启后读回；不代表自动迁移浏览器数据 |
| 产品入口 | 独立启动真实 main.cjs，并确认窗口完成加载；另通过本地 EXE 启动器打开可见 Electron 窗口 |

带真实论文的验收包含 16 项初次运行检查、3 项完整进程重启检查，另有产品入口检查。运行路径和结果见 `.runtime/desktop-shell/verification-latest.json` 指向的本地报告；失败记录保留，不与成功报告混淆。相关协议和共享前端回归独立运行。

当前结果为 20 项桌面端到端检查、10 项邮箱账号专项检查、8 项 GitHub 专项检查、51 项本地协议及共享前端回归通过，桌面和网页版构建与原生开发启动器编译通过。窗口检查覆盖原生标题按钮避让、整行布局、菜单焦点、主题同步、原生历史、最大化/还原和窗口位置重启恢复。布局矩阵覆盖中英文、1320/1120/1100/1000/960px 窗口及 100%/125%/150% 界面缩放，共 30 种组合。界面缩放模拟不能替代不同 Windows DPI 的实机验收。可选的浏览器导航专用测试因当前未配置 Playwright 路径而跳过，不计入通过数量。

修复了共享响应式规则在窄窗口隐藏顶部导航、桌面又隐藏移动导航而导致入口消失的问题。可用界面宽度不超过 1100px 时，主导航收进桌面菜单，复用共享 PlayerNavigation 的路由、翻译和激活状态；键盘仅聚焦当前可见项。菜单限宽、限高并允许内部滚动。标题中间保留至少 32 CSS px 的独立原生拖拽空白区，测试同时断言入口可见性、横向顺序、纵向边界和系统按钮避让。

可见窗口另经 Windows 系统“大小”操作从约 1283px 调整到约 988px，确认主导航收纳及系统按钮布局。实查发现菜单导航项受顶部导航样式影响而过密，已修复为至少 36px 点击高度，当前矩阵同时验证点击高度和菜单不超出窗口底部。

桌面专用样式使用 8px 滚动区与 6px 可见滑块，轨道透明、无两端箭头，悬停/拖动使用主题强调色。根页面和 PDF 工具内部的滚动条宽度、三种主题颜色、实际滚轮与 Ctrl+Home 滚动均已纳入 Electron 回归。保留原生滚动行为，不改变 overflow，不注入第三方游戏 iframe，也不改网页版滚动条。

返回、前进连接 Electron 的真实导航历史，支持 Alt+左右箭头；桌面菜单提供集成与 Agent、Ctrl+R 刷新、F11 全屏、说明和 Ctrl+Q 退出。标题空白区支持原生拖拽和双击最大化/恢复。当前关闭即退出预览，不设托盘后台模式；本地 `window-state.json` 保存窗口尺寸、位置和最大化状态，恢复时处理显示器断开。仅在页面自身发出未完成操作的 `beforeunload` 信号时提供继续编辑/退出选择，未新增全局脏状态跟踪。

本轮可见窗口实查通过：工具导航、返回按钮、Alt+右箭头前进、三种主题及原生按钮同步、桌面菜单、双击标题区最大化、原生恢复按钮、应用全屏和 Esc 退出；原生关闭按钮退出后，重新启动恢复尺寸和位置。标题区系统菜单和系统移动操作已实查；本轮用户另在真实窗口确认“拖动和缩放都正常”，鼠标拖拽及边框缩放计为人工实测通过。自动化鼠标拖拽注入未观察到位移，保留这一工具限制，不用程序设置位置冒充鼠标拖拽通过。预览的未登录主题选择仍沿用共享宿主行为，重启后回到系统主题，不宣称已保存主题偏好。未验证不同 DPI 和系统贴靠布局。

隐藏窗口进入/退出全屏后曾遇到 compositor `UnknownVizError`，该次验收未计为通过，保留独立运行目录。全屏以可见窗口实查，自动回归保留最大化/还原；失败报告增加诊断超时与截图错误处理，避免原始失败被报告器异常掩盖。

构建保留既有大 chunk 警告。OCR 库对部分语言参数发出非致命警告，本轮识别结果正确，不据此承诺所有 OCR 样本均通过。UI 实查以当前窗口尺寸为准，其他 DPI、干净 Windows 安装和长期运行仍待验证。

## 本地账号与会话

邮箱登录直接使用共享 AccountPage、bootstrapAccountSession 和现有认证 API 客户端。主进程的固定账号调用桥复用 Windows DPAPI 库，并按 API origin 隔离凭据；会话刷新与退出串行化，旧登录结果不能在退出后重新写入令牌。网络错误保留密文供恢复，401/服务端撤销清除会话，离线退出仍清除本地凭据。损坏凭据不恢复登录，保留可重新登录的界面。认证 API 和数据库结构未修改。

账号验证使用实际认证服务、内存测试仓库和模拟邮箱/OAuth 提供方，无数据库、SMTP 或生产配置。10 项 Electron 邮箱专项检查覆盖共享界面、DPAPI、刷新与进程重启、退出及令牌隔离；另有 8 项 GitHub Electron 专项检查，实测系统浏览器访问本地模拟页、取消和拒绝授权、登录、完整重启恢复、退出与令牌隔离。邮箱和 GitHub 各有 8 项服务层检查，包含原有账号/桌面回归合计 51 项本地检查通过。报告分别见 `.runtime/desktop-shell/account-verification-latest.json` 和 `github-verification-latest.json`，桌面原有验收仍独立记录，不用账号专项替代游戏/PDF/OCR 验收。

GitHub 使用共享等待/轮询页面与现有 API，系统浏览器只能打开当前挑战签发的授权链接。先取得不含令牌的结果标记，待共享页面接受后才持久化登录；取消、离开页面或新尝试会作废旧结果，避免迟到授权恢复会话。对截图中自动验收的旧链接重复提交所产生的拒绝，模拟回调页现已显示明确说明并清理 URL 参数。真实服务端认证 API 未作修改。并行 Electron 验收出现非致命 GPU 缓存访问警告，各项仍通过，未关闭 sandbox 或 webSecurity。

操作方式见 [桌面 README](../apps/desktop/README.zh-CN.md#github-系统浏览器登录)。账号可通过原有参数连接 loopback HTTP，或通过专用 `--test-account-api` 参数连接隔离 HTTPS 测试实例，后者使用按 origin 派生并绑定的独立 profile；默认普通预览不联网。HTTPS 传输、实例检查、隔离存储与会话恢复已用本机服务验证，GitHub 已完成系统浏览器和本地模拟提供方验证，尚未连接公网测试服务器或真实 GitHub OAuth App。头像上传、发布、后台执行及其他服务器业务未因此开启。

## 使用与后续

在仓库根目录运行 `start-mooyu-desktop-preview.bat`。构建完成后可双击 `.runtime/desktop-shell/MooyuDesktopPreview.exe`。这是依赖开发机既有运行时和构建资源的预览，尚未打包为可分发桌面产品。旧 D1/WinForms 诊断及其论文依赖不纳入本次提交，工作区实现保留并另行验证。

下一阶段在本地安全会话验证基础上接入经过授权的远程测试环境和系统浏览器授权，再按完整功能矩阵验证文件、创作者和研究业务，以及 Windows 能力执行闭环；不以单一论文流程代替整个平台验收。

本轮未提交、推送或部署，没有调用模型、上传论文、发送真实邮件或验证码、发布内容或访问生产数据库。
