# F1.3b-2b-2c-2b-1：本地 PDF 确定性页面渲染基元

状态：参考实现与自动化验证已完成
日期：2026-10-29
边界：已经运行真实 PDF 解析与 PNG 栅格化；尚未发布签名生产组件，也没有接入版面模型或 OCR。

## 1. 已完成内容

新增严格的 `paper-pdf-render-request-v1` 与 `paper-pdf-render-manifest-v1`：

- 请求绑定源 PDF 路径、SHA-256、精确升序页码、缩放、背景和输出位置；
- 限制源文件大小、文档页数、单页像素和总输出字节；
- 清单记录文档总页数、逐页 PNG 路径、尺寸、旋转角、字节数和 SHA-256；
- 清单同时绑定 `pdfjs-dist@6.4.299`、`@napi-rs/canvas@1.0.11`、平台和 CPU 架构；
- 成功清单必须精确覆盖请求页集合，不能缺页、增页或交换页码。

## 2. 本地与离线边界

参考渲染器直接消费已获授权的本地 PDF 字节：

- 禁用 Range、流式下载、自动拉取和 worker 网络路径；
- CMap、标准字体、WASM 和 ICC 资源全部指向固定版本包内目录；
- 不使用系统字体，不向服务器上传 PDF、页面或渲染结果；
- 输出目录必须是新目录，已有目录会被拒绝，避免旧产物重放；
- 源文件在打开前后复验普通文件身份、大小、修改状态和 SHA-256。

服务器 4 核 8G 不参与渲染。

## 3. 输出完整性

每页先编码为 PNG 临时文件，再原子 rename 到最终名称。全部页面完成后才发布清单。独立验证器会：

- 拒绝链接、额外根目录项、额外页面和非普通文件；
- 重新计算每个 PNG 的大小与 SHA-256；
- 重新验证清单、页集合、像素和总字节限制；
- 发现源摘要变化、页面篡改、超限、取消或解析失败时删除不完整输出目录。

确定性结论仅限同一已冻结渲染器、栅格器、平台和架构；不宣称不同原生平台生成逐字节相同 PNG。

## 4. 自动化证据

自动化测试实际构造并解析两页 PDF，完成真实 PNG 渲染并验证 PNG 文件签名。覆盖：

- 两次独立渲染得到相同逐页摘要；
- 精确页尺寸和进度顺序；
- 页面文件被修改后复验失败；
- PDF 摘要变化后拒绝并清理；
- 单页像素超限在编码前拒绝；
- 已取消请求不保留部分页面。

专项回归 5/5 通过。
