# Harness 0.0.10 离屏样本验收证据

日期：2026-09-24。完整结论及未覆盖项见 [文档 24](../../24-harness-offscreen-integration.zh-CN.md)。

获准范围是本机 `http://127.0.0.1:3083/` 的 Harness 游戏大厅，测试点击、名称输入、方向键、结束和重新开始。画面由浏览器工具截取，只包含该页面。未操作其他应用，未使用系统键鼠，未启动原版桌猫。

| 文件 | 内容 |
| --- | --- |
| `01-input.png` | 得分 1、名称“侧栏验收”、3 次右方向键并释放后的游戏画面 |
| `02-restarted.png` | 新会话中得分和名称恢复默认值 |
| `03-stopped.png` | 结束样本后清空画面、禁用控件 |
| `04-processes-after-stop.json` | 结束后按固定运行时 EXE 路径过滤，匹配进程数 0 |
| `05-tab-closed.txt` | 运行中关闭游戏大厅标签后的页面 DOM，游戏 iframe 已移除 |
| `06-processes-after-tab-close.json` | 关闭标签后，同一固定运行时的匹配进程数 0 |
| `07-lifecycle.json` | 三个会话的 entry-loaded、app-ready 和 stop 日志 |

这些证据支持样本正常输入、重启和退出路径。没有独立窗口观察器、声音采集、延迟统计或全部进程树审计；不构成任意 EXE 的兼容性证明。截图中 22—23 帧是播放器最近一秒的现场读数。
