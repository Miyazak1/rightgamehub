## QQ 文章图片与定时文章的边界

能力插件由小墨鱼共享。QQ、网站 Chat、定时调度是不同触发入口，按各自权限、预算和计划调用能力；正文草稿、网站文章、文字回执与图片是不同输出形式。QQ 明确要求文章时，可以调用写作能力，再由展示／投递模块渲染长图或分页图发群，不需要改动网站定时文章计划。

目前真实验收通过的是写作、草稿保存和完成通知；文章正文渲染图片并发群尚未实现，本轮未将其计为通过。后续接入应保留原定时入口，单独处理 QQ 图片渲染、超长分页、发送账本与重试。全局停用 GitHub 插件会影响所有调用者，应与渠道级启停区分。
