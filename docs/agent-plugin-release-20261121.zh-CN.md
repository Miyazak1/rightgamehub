## 发布前必须取得的现场证据

当前没有服务器只读清单，因此“线上已可直接切换”尚不成立。未来需要从原 Compose 标签取得全部配置文件顺序、项目名、镜像 ID、环境与 secret 文件绑定、网络别名、挂载、服务启用状态。私有快照保留在服务器私有备份目录，不打印配置内容或凭据。

保留 QQ 登录网关镜像、数据卷名称及挂载来源；保留 Agent 和 QQ 两个数据库、参与者权限、策略版本、定时计划和原镜像。验证备份可读及校验和。不要重新生成 shared secret、重建登录目录、重置历史／预算、执行 down -v 或恢复旧数据库来回退代码。

现有 `deploy/compose.prod.yml`、`deploy/qq/compose.yml` 和 `update-admin.py` 只覆盖原服务／管理通道，尚未装配共享交互执行器及全部新开关。不能把旧 update-admin／switch-compatible 工具直接当成本次发布器。

## 配置与服务矩阵

| 进程 | 必须核对 | 保留项 |
| --- | --- | --- |
| API | `AGENT_INTERACTIONS_ENABLED`、Agent ID、插件禁用列表、图片 v1 接口、现有 Agent 主密钥、GitHub 配置 | 原数据库、secret 文件、后台入口和定时设置 |
| 共享交互执行器 | 与 API 同一候选镜像／Agent／插件版本；现有主密钥、模型与 GitHub 配置；独立进程 `agent-interaction-worker-cli.mjs` | 原 Run、工作流版本、能力授权和预算账本 |
| QQ worker | `QQ_AGENT_INTERACTIONS_ENABLED=true`、管理通道开启、同一 Agent／shared secret、内部 API 地址可达 | 原 config、控制设置、允许群／用户、QQ 数据库及登录网关 |
| 原定时文章执行器 | 原启用状态、配置、计划、调度协议与原角色 | 不随 QQ 图片投递改变发布节奏或策略 |

API 和共享执行器的插件配置必须一致。QQ 内部 API 主机名受客户端白名单约束，不能随意改成任意域名；先验证原网络中别名 `api` 的解析和签名请求。论文相关六个开关全部保持 false。没有构造会覆盖原复杂 Compose 链的简化文件。

## 受控切换顺序（尚未执行）

1. 暂停新请求受理；原正在运行的研究、定时 fire 和发送任务完成或进入明确保留状态。不能停用原定时计划来冒充无影响；应选择无活动 fire 的切换窗口。
2. 检查所有 `queued/ready/sending/needs-review` 的 QQ 消息及未完成图片页。未知投递先核对，不自动重发。固定原服务镜像与挂载快照，验证两库备份。
3. 只在原业务库应用已审阅的追加迁移 0166，注册插件已有工作流／合约；不自动授予能力、不修改计划。新任务必须保留精确插件绑定。
4. 在暂停受理的窗口先升级 API，再启动／升级共享交互执行器；用只读能力状态验证版本和权限。新旧执行器不得同时竞争同一待执行任务。
5. 停旧 QQ worker，按原网络／配置／secret／数据库绑定启动新 worker。`enableAgentBridge` 幂等创建 `agent_image_pages`。不启动第二个消费同群的 worker，不重启登录网关。
6. 验证原账号仍在线、历史／权限／定时配置未变、HMAC 操作可达，再恢复受理。以独立测试群验收文字、源码补读、完整分页文章和重启防重；失败保持队列与记录。

## 回退门槛与顺序

`assessAgentPluginRelease` 是无副作用判定器，要求显式证据，不执行部署。升级与回退都要求备份、镜像、挂载、secret、论文关闭和空闲状态。回退另要求旧插件实现保留。

**有任何未完成图片页、待投递消息、运行任务／fire 或未知投递，均不得直接回退旧 worker。** 旧 worker 不理解图片页，会把页标题当普通文字处理并写成已发送。应保留图片版 worker 和账本，先完成／核对已有发送；不能删除页表、改为 delivered 或丢弃队列来通过门槛。

安全窗口内暂停新受理 → 停共享执行器／消息 worker → 保留追加 schema 与全部历史 → 恢复原 API／执行器镜像与配置 → 仅在图片队列确认为空后恢复旧 QQ worker → 核对原权限与登录再恢复受理。保留任务所需旧插件版本；缺失版本应等待，不能将旧任务改绑新版本。无需回退前端或网关，除非其独立变更另有验收。

本方案与候选产物不构成线上部署授权；当前工作只准备本地可审查结果。下一阶段 QQ 渠道插件另分支开发，不能覆盖此冻结候选。
