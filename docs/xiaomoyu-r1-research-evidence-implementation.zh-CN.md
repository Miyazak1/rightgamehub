# 小墨鱼 R1 项目研究证据包与选题记忆实施方案

版本：R1-E2

状态：基线完成；语义聚类、关系扩展与评测扩容进入后续增量

更新日期：2026-10-27

## 1. 目标

R1 把博客当前依赖的 GitHub 工具输出升级为跨工作流可复用、可定位、可修订的研究证据包，并建立项目、主题、观点和冷却期记忆。它服务后续 GitHub 项目研究、网页研究和论文阅读，不建设博客专用的第二套证据库。

## 2. 已冻结的数据映射

| 领域契约 | 现有权威对象 | R1 做法 |
| --- | --- | --- |
| `ResearchArtifact` | `tool_research_sources` | 直接复用稳定来源身份与规范 URL |
| `ArtifactVersion` | `tool_research_source_versions` | 直接复用不可变内容哈希、取得时间和版本定位 |
| `EvidenceSpan` | `tool_research_evidence` | 直接复用短证据、定位器、用途与不可变约束 |
| Foundation 执行产物 | `agent_tool_artifacts` | 继续作为工具调用事实来源，不复制内容所有权 |
| 执行—研究链路 | `agent_research_artifact_bindings` | 新增加式绑定，连接 Run / Stage / Action / Tool Artifact 与资料版本 |
| 产物—证据链路 | `agent_research_evidence_bindings` | 新增加式绑定，记录一个工具产物实际产生的证据片段 |
| 文章引用—证据链路 | `blog_revision_citation_evidence` | 新增加式绑定，把不可变文章修订中的引用 UUID 落到具体 `EvidenceSpan` |

禁止为博客另建 `blog_sources`、`blog_evidence` 或语义相同的平行表。论文特有的 DOI、arXiv、版面和 PDF 解析对象留给 R2 增加式扩展。

## 4. 当前证据与资料施工包的不变量

1. `agent_tool_artifacts` 是某次工具调用返回内容的不可变事实；
2. `tool_research_source_versions` 是跨运行复用的资料版本；
3. 多次运行读取同一内容版本可以绑定到同一资料版本，但每个 Tool Artifact 只有一条绑定；
4. EvidenceSpan 必须带版本与可回跳定位器，不允许只保存模型摘要；
5. 人格影响选题偏好，不改变资料身份、证据事实或权限；
6. 证据归档失败时 Foundation 阶段失败关闭，不允许继续生成无法追溯的文章；
7. 当前只有一台生产服务器；R1 验收按同机多进程与单机恢复设计，不虚构多主机部署。
8. 生产 Foundation 落稿必须做到“一个入选资料对应一个引用，且每个引用至少绑定一个 EvidenceSpan”；不完整覆盖必须与文章写入在同一事务中回滚。
9. GitHub 官方资料只允许从 `api.github.com` 读取，仓库文档中的 URL、命令和提示词不产生新的网络请求或权限。
10. 新材料契约不能原地改变 `research.github.repository.read@1`；历史 Run 必须始终可以按原契约解释。
11. 编辑记忆只在文章公开发布成功时写入；失败、私有草稿和撤回操作不能制造“已经选过”的假历史。
12. 单项目主角排除是粘性的永久事实；对比使用不能解除它。对比项目与比较组合分别使用 30 天和 180 天冷却。
13. 模型分项分数只用于排序与审计，不能越过许可证、风险、证据、历史主角和冷却期等确定性门禁。
14. 新运行使用 Foundation 工作流 v2 和运行输入 v2；历史 v1 工作流、运行输入与选题产物仍可读取和重放。
15. 当前主题与观点近似重复使用确定性字符二元组相似度作为第一版门禁，不得把它表述为完整语义理解；模型辅助聚类必须晚于离线评测和证据可解释性设计。
16. 项目重研必须追加 `project-version-observed`，保存本次资料版本、前序事件、版本关系和研究理由；不得覆盖上次研究版本。
17. 已发布核心判断通过不可变 `agent_editorial_claim_relations` 绑定实际 EvidenceSpan；支持、反对、背景、未知和修订使用同一闭集关系，不允许自由文本关系替代结构化语义。
18. 显式不确定结果允许非终态 Action 进入 `uncertain`，但必须由运行时失败路径明确声明；0144 迁移保持数据库状态机与运行时契约一致，禁止把未知提交结果错误归类为普通失败或安全重试。

## 5. 退出标准

R1 只有在以下条件全部满足后完成：

- 新文章的项目事实能够定位到不可变来源版本和 EvidenceSpan；
- README、Docs、Release、License 至少四类官方资料可被独立识别和引用；
- 单项目主角、主题和核心观点重复率可计算并受门禁约束；
- 候选淘汰原因、证据覆盖率和成本可以在后台审计；
- 已发布文章继续冻结原证据，不随资料更新静默变化；
- R2 论文适配器不需要新建运行时、Provider、预算、引用或追问基础设施。
