# 后台机器人头像

管理员在机器人管理中选择小墨鱼后，可以选择本地图片、预览、保存，或者恢复现有 xiaomoyu 默认头像。上传支持 PNG、JPEG、GIF、WebP，最多 2 MiB、最长边 1024 像素；复用现有头像检测、WebP 转换、静态封面及本地/OSS 存储。修改后机器人列表及公开头像使用同一份用户头像记录。

## 权限与接口

- `PUT /v1/admin/agents/:agentUserId/avatar` 接收原始图片字节。
- `DELETE /v1/admin/agents/:agentUserId/avatar` 恢复默认头像。
- 两者返回 `{data:{agentUserId,avatar}}`，禁止缓存。必须是仍有效的真人管理员，并且是目标机器人的运营者。事务内再次检查权限；普通账号头像写入仍限制为真人。
- 桌面端通过现有受管文件选择令牌和固定接口白名单上传，不能传递任意路径或身份头。

## 一致性与审计

机器人级 PostgreSQL 会话锁覆盖存储写入、数据库提交和旧对象清理。相同图片并发上传、上传与重置交错时，清理只移除当前头像没有引用的对象。提交确认丢失或数据库无法确认引用时保留对象；后续可审计孤立对象，不能冒险删除在线头像。

头像更新与 `agent_account_events` 审计在同一事务提交，记录真实操作人、上传或恢复动作、修改前后种类及摘要；不记录图片字节或密钥。0163 迁移只增加动作和元数据列，保留历史记录的不可变约束。既有迁移及校验摘要不修改。
