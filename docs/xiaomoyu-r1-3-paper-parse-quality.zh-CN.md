# 小墨鱼 R1.3 论文解析质量基线与可靠性门禁

版本：v1.0
日期：2026-10-27
状态：代码、迁移、冻结评测集和后台只读观测已实现；论文仍只进入私有研究，不进入公开发布

## 1. 阶段目标

R1.3 解决的不是“能否从 PDF 拿到一些文字”，而是“这份文字是否足以被后续研究可靠使用”。解析成功不再等于阅读成功。每个新取得的论文版本都必须经过确定性版面门禁，生成不可变质量快照；模型不能自行提高等级，也不能绕过允许用途。

既定运行边界保持不变：

- 只有一台生产服务器；
- 小墨鱼公开写作仍由北京时间每天 10:00 的现有计划负责；
- 论文研究不接入公开选题、写作和发布链路；
- 不启用 OCR，不执行论文附件，不把图片、公式或表格猜成事实；
- 所有来源正文均按不可信数据处理。

## 2. 版本化合同

工具升级为 `research.paper.arxiv.read@2`，输出为 `paper.arxiv.read.output@2` / `arxiv-paper-research-v2`。输入合同仍为 `paper.arxiv.read.input@1`，避免无意义地改变稳定定位器。

质量合同为 `research.paper.parse-quality@1`，策略版本为 `paper-text-layer-gate-v1`。质量快照一对一绑定 `agent_paper_versions`，写入 `agent_paper_parse_assessments` 后禁止更新和删除。

质量等级只有三种：

| 等级 | 允许用途 | 含义 |
|---|---|---|
| `trusted-text` | `analysis,citation,comparison` | 文字、顺序与证据覆盖均通过，可以进入后续语义研究 |
| `limited-text` | `analysis` | 可做内部理解，但不得引用或比较 |
| `blocked` | 无 | 不得进入语义阅读；证据仍只作为诊断与审计材料保存 |

## 3. 确定性信号和阈值

系统逐页测量：文字字符数、空页、疑似扫描页、多栏、阅读顺序回跳、表格行、公式符号和图片绘制操作；整篇测量文字页覆盖与页级证据覆盖。

策略 v1 的失败关闭阈值：

- 文字页覆盖低于 75%：`blocked`；
- 页级证据覆盖低于有文字页面的 75%：`blocked`；
- 阅读顺序风险页超过总页数 25%：`blocked`；
- 有风险但未触发阻断阈值：`limited-text`；
- 无风险原因码：`trusted-text`。

原因码固定为：空白文本页、扫描页、低文字密度、阅读顺序不可靠、多栏、表格结构未还原、公式结构未还原、图片内容未读取和证据覆盖不足。原因码来自代码，不来自模型自由文本。

## 4. 冻结评测集

`tests/platform/fixtures/paper-layout-quality-eval-v1.json` 是首个版本化版面评测集，覆盖：

1. 干净单栏文本；
2. 双栏回跳导致的阅读顺序风险；
3. 表格网格；
4. 公式与图片混排；
5. 部分扫描页；
6. 页级证据覆盖缺口。

评测只使用冻结输入和确定性代码，不调用模型、不访问网络、不写数据库。策略或解析器升级必须新建版本并同时保留旧结果，禁止就地改变历史等级。

## 5. 证据与持久化

arXiv 适配器保证每个有文字页面至少选取一个证据块，再在总上限 96 个内补充其余文本，避免前几页耗尽额度导致后页无证据。

归档时：

- `trusted-text` 证据可以分析、引用和比较；
- `limited-text` 证据只能分析；
- `blocked` 证据的 `allowed_uses` 为空；
- 质量快照哈希与论文版本、解析器版本、策略版本共同进入审计链；
- 同一论文版本若出现不同质量哈希，事务以 `AGENT_PAPER_PARSE_ASSESSMENT_CONFLICT` 失败关闭。

## 6. 后台观测

机器人运行概览新增只读 `paperResearch`：累计验收数、可信/受限/阻断数量、最近论文、解析器、策略、原因码、文字覆盖和证据覆盖。运行时间线新增该次运行绑定的论文质量快照。

后台明确显示“论文仅用于私有研究，不进入公开发布”。该视图不提供人工修改等级、强制放行或逐篇审核按钮。

## 7. 验收条件

R1.3 只有同时满足以下条件才可提交：

- 冻结评测集结果稳定；
- 合同 v2、旧 v1 读取兼容和失败关闭测试通过；
- 0146 迁移在真实 PostgreSQL 成功且不可变触发器生效；
- 论文端到端数据库测试产生一条版本、一份版面、一份质量快照和证据绑定，不产生公开文章；
- 后台生产构建通过；
- API 生产镜像能加载 v2 适配器；
- 文档明确说明 OCR、复杂版面语义、论文观点抽取、比较和发布仍未开放。

## 8. 下一阶段

R1.4 才进入单篇论文语义阅读：章节重建、作者主张/实验结果/系统推断分层、结论—证据图和基于冻结证据的追问。R1.4 只能消费 `trusted-text`；`limited-text` 必须停在内部诊断，`blocked` 不得调用语义模型。
