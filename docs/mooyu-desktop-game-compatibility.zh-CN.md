# 桌面游戏兼容性验收

本轮只修改本地客户端。正式服务仅用于已授权的公开目录、资源和实际窗口运行检查；成绩提交在本机回环契约服务验证，没有向正式排行榜写入测试分数。这里的“接口接通”不等于已完成所有游戏验收。

## 已修复的共同链路

- 本机存档使用绑定的服务 origin 和服务端用户 ID；内部 `mooyu-app` 地址不参与存档作用域。匿名与账号、作品、频道保持隔离，保留已有存档。
- 游戏会话与成绩操作复用网页版 API。桌面主进程仅接受固定方法、严格字段、有限指标及回放证据；不接受 URL、任意请求头或权限注入。
- 创建游戏会话前必须已有来源校验通过的同作品、同版本、同频道运行描述。成绩操作还要求当前账号中已登记、未过期且获准 competition 的会话。
- 退出账号会清除本地游戏授权；旧请求迟到的响应不能恢复权限。游戏 iframe 不取得账号 bearer 或游戏会话令牌。

## 验收层次

| 层次 | 验证方法 | 不能据此推断 |
| --- | --- | --- |
| 公开目录与能力 | 读取当前站点作品及运行描述，严格校验版本运行域 | 游戏逻辑、SDK 功能均正常 |
| 入口资源 | 对公开 HTML 入口进行 HEAD 检查 | 画面、输入、存档或联网正常；单次超时也不能证明服务失效 |
| 实际窗口 | 在本地 Electron 中观察画面与执行具体交互 | 未执行的云同步、计分、多人对局已验收 |
| 游戏成绩契约 | 真实 SDK → 宿主 MessagePort → 桌面 API facade → 主进程会话 → 既有本机 HTTP 路由 | 正式数据库中的成绩已验证，或独立测试实例已升级 |
| 本机存档契约 | SDK 读写、重开恢复、账号隔离，使用临时本地存储 | 网页与桌面本地进度会自动互相同步 |

## 本轮现场记录（2026-11-02）

公开目录共 20 个作品，19 个使用隔离运行入口、1 个为平台内置游戏。声明 competition 的作品 6 个、localSave 4 个、shareLinks 4 个、multiplayer 2 个，功能会重叠。逐项入口观测记录保存在本机 `.runtime/desktop-game-compatibility/catalog.json`，不提交该运行产物。

- 粒子试验场：实际窗口 WebGL 2 正常，星核喷泉切换到引力星环成功。直接入口检查曾超时，因此以实际窗口结果记录，不把网络探测超时认定为程序故障。
- 0hh1 填格游戏：主菜单、教程棋盘与“不计入排行榜”状态正常显示；未开始或完成正式计分对局。
- 2048：游戏画面与排行挑战准备状态可见，返回自由模式后提示恢复进入挑战前的进度。未进行提交分数操作；不能据此宣称正式成绩写入或回放校验已验收。
- 英语填空练习：上一轮已验证学习目标页及本机存档管理可读，未重置已有进度；本轮成绩接口在本地验证，尚未执行正式学习记录同步。
