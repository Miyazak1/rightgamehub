# P0.5-A：轻社交基础闭环

日期：2026-09-29。范围：公开玩家卡片、关注、屏蔽、隐私与猜百科排行榜；不包含私信、自由发帖或群聊。

## 本阶段目标

形成第一条社交回流路径：完成猜百科 → 进入休息室看今日榜 → 关注玩家 → 切换关注榜 → 第二天继续参与。

## 已实现

- `0021_social_foundation.sql`：玩家简介与 `public / followers / private` 可见性、关注关系、双向屏蔽关系；
- 服务端社交策略：禁止关注或屏蔽自己；任意一方屏蔽后双方资料和榜单成绩互不可见；屏蔽会同时清除双方关注；私密账号不能被关注；
- 猜百科今日榜：全站榜与关注榜，按提示次数、猜测字符数、用时和完成时间排序；
- 成绩写入改为保留同一次真实最佳尝试，不再把多次成绩的不同最小字段拼成不存在的成绩；
- 共享前端“休息室”：玩家卡片、简介与可见性、今日榜、关注/取消关注、确认后屏蔽；
- OpenAPI、TypeScript 声明与共享 API 客户端同步。

## 明确不做

本阶段不加入私信、聊天室、自由文本动态、图片评论和陌生人推荐。社交关系只围绕结构化成绩发生，降低骚扰、垃圾内容和审核面。
