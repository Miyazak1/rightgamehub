# P0.9 社区项目发现

## 目标

让插件不仅能玩官方游戏，也能自动展示社区作者发布的轻量项目，并保持 GameHub 的安全发布闭环。

## 已实现

- 作品资料新增预计时长、发现标签、Coding Agent、GitHub 仓库与 SPDX 许可证。
- 发现页新增「社区在玩」，只读取已经发布、通过校验且仍启用的真实作品。
- 社区排序由真实游玩次数与收藏数生成，收藏的权重高于一次游玩；不依赖人工排位。
- 卡片与详情页展示作者、时长、Agent 共创和开源信息，搜索同时覆盖这些字段。
- GitHub 仅作为外部源码链接展示；平台不会自动拉取、构建或执行仓库代码。
- 新建作品页可填写发现资料；开源地址与许可证必须成对提交。
- 原有隔离运行、内容举报、管理员处置和版本撤下机制继续生效。

## 自动发现规则

1. API 只返回 `published + public` 的作品。
2. 作品必须存在校验成功且处于启用状态的当前 Web release。
3. 官方《猜百科》保留在每日推荐，社区橱窗排除官方内置项目。
4. 社区热度分数为 `playCount + saveCount × 4`，同分时优先最近发布。
5. 没有真实社区作品时不填充伪造项目，橱窗自然隐藏。
