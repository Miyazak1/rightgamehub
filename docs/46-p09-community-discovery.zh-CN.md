# 首页与社区作品发现

## 当前体验（2026-10-08）

首页服务于快速找到并打开作品，保留像素视觉和浏览器、Cursor、VS Code、Harness 的共享界面。旧版「今日摸鱼」「社区在玩」「换个脑子」的多次重复陈列已替换为：

1. 顶部搜索：按标题、介绍、标签、作者或 Agent 检索公开作品。
2. 最近玩过：仅登录且存在记录时出现，最多三项；读取当前账号已有的游玩记录，不读取云存档。
3. 推荐游玩：首批精选《猜百科》和《2048》，只从本次已成功加载的可用目录中取值。测试作品《迷阵》保留在完整目录中，并标明「联机测试」，不进入推荐。
4. 全部作品：包含推荐作品，支持游戏、互动、工具筛选及「加载更多」。搜索或筛选时隐藏辅助栏目，集中呈现结果。
5. 最新分享：最多展示三条已审核公开内容的文字摘要，链接到分享详情。未开放、无内容或请求失败时隐藏，不阻断作品目录。

窄窗口底部导航固定为「游玩 / 游戏库 / 分享 / 创作 / 更多」五项；共建、安装、账号和管理员入口放入更多菜单。菜单支持 Escape 和失焦关闭。访客入口明确显示「登录」，浏览器宿主标记为「网页版」。

## 查询与资源边界

- `GET /v1/works` 保持原有数组响应，新增 `q`（最多 100 字符）、`offset`（0–100000），并保留 `kind`、`limit`（1–50，默认 20）。首页每次请求 24 条。
- 先筛选、再分页：作品必须公开且已发布，并存在当前已发布、校验完成、启用中的 release。Windows 作品也可展示，但入口明确标识启动平台。
- 官方内置《猜百科》参与搜索、类型过滤和分页；匹配时固定在首位，占用一条名额，不会跨页重复或挤掉社区作品。
- 搜索采用大小写不敏感的字面子串匹配，`%` 和 `_` 不作为通配符。发布时刻和作品 ID 组成稳定排序。
- 前端搜索防抖 250 ms；取消旧请求，并通过请求代次检查防止过期结果覆盖当前列表。分页失败可重试。
- `GET /v1/me/library?recent=true&limit=3` 只取当前账号最近玩过的三条记录；未带参数的游戏库请求保持原行为。账号切换时清空首页私有状态；游客不请求游戏库。
- 分享复用已有公开列表接口，首页仅取前三项，不预加载分享图片，不新增轮询、后台推荐任务或数据库迁移。公开目录保留 30 秒缓存，私有游戏库继续 `no-store`。
- 云存档保持关闭，本地存档不受本次改动影响。

## 作品信息与封面

`catalog-presentation.mjs` 对首批已知作品提供展示层文案修正，覆盖旧的英文源码介绍、仓库名和占位介绍，过滤 `github-import` 技术标签，不写回作者原始资料。作者修改作品标题后不再套用该作品的修正文案；介绍仅在仍为原始占位值时替换，已有业务标签保留。

《OI 重开模拟器》的名称和介绍依据[项目 README](https://github.com/Miyazak1/oi-remake-game)核对。中文展示内容参与目录检索。

有真实封面的作品继续使用原封面。无封面的作品使用中性的像素网格占位，不借用其他游戏画面。演示图集使用独立 SVG 视窗裁切，避免相邻图块露出。

## 验证与发布

- `tests/platform/discovery-catalog.test.cjs` 使用独立临时 PostgreSQL 数据库，覆盖超过一页的目录、筛选顺序、分页、可见性、特殊字符、编辑文案和当前账号最近游玩记录。测试结束删除自己的临时库。
- `tests/client/discovery-browser.test.cjs` 运行真实共享 React 界面和 API 客户端，使用本地接口夹具验证搜索、分页、重试、账号切换、分享降级和窄屏导航，并生成浅色、深色和 390/360 px 截图。该验证不等同于新版本的人工安装验收。
- 客户端包版本：VS Code / Cursor `0.3.31`，Harness `0.1.13`。数据库迁移总数仍为 51。
- 更新前需构建网页与安装包；线上使用既有 `deploy/update-community-sharing.sh <完整提交 SHA>`，发布后检查版本与健康状态。

## 历史背景

P0.9（迁移 `0027_community_discovery.sql`）引入作品预计时长、标签、Agent、GitHub 和许可证资料，以及按游玩/收藏热度展示的社区橱窗。本次只替换首页陈列和目录查询，作者资料、源码外链、安全发布、举报与撤下机制继续保留。
