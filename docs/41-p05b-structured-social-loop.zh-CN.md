# P0.5-B：结构化社交回流

日期：2026-09-29。范围：猜百科成绩卡、当日挑战链接、固定像素反应和站内通知；仍不包含私信、自由发帖、图片评论或群聊。

## 产品闭环

完成今日猜百科 → 复制成绩卡或发起当日挑战 → 对方通过链接查看发起者结构化成绩 → 完成同一道题 → 在休息室使用固定反应回应 → 发起者收到站内通知。

## 已实现

- `0022_structured_social_loop.sql`：固定反应、结构化通知和当日挑战表；挑战必须引用发起者已完成的真实成绩；
- 固定反应仅有 `GG / 精彩 / 惊了 / 歇会` 四种，一个玩家对同一成绩只保留一种，可切换或撤回；
- 关注与反应生成站内通知，支持未读状态和全部已读；屏蔽关系与玩家卡片隐私同时约束榜单、反应、通知和挑战访问；
- 成绩卡只复制日期、名次、提示数、猜测字符数和用时，不包含代码或项目状态；
- 挑战只允许当天创建，到次日中国标准时间零点失效；挑战页比较同一天、同一道题；
- 休息室增加固定反应条、自己的“复制成绩卡 / 发起挑战”操作和轻量通知栏；新增像素风挑战落地页；
- OpenAPI、TypeScript 声明和共享 API 客户端已同步。
