# 作者指南：从 GitHub 导入作品

状态：适用于 G1 只读导入
更新日期：2026-09-30

## 能做什么

GitHub 导入会帮你建立作品资料和可追溯来源，减少重复填写。它会读取你明确授权的仓库名称、介绍、默认分支、README、许可证，以及当时的固定 commit。

它不会运行源码、安装依赖、自动构建或自动发布。导入结束后，你仍需上传已经构建好的 Web ZIP。

## 操作步骤

1. 进入“我的作品”，选择“从 GitHub 导入”。
2. 点击“连接 GitHub App”，在 GitHub 只选择准备导入的仓库。
3. 返回平台，选择连接和仓库，再点击“只读预览”。
4. 检查仓库、固定 commit、许可证和 README 摘要。
5. 修改作品名称、介绍和类型，创建私有草稿。
6. 上传 Web ZIP。ZIP 根目录必须有 `index.html`，之后仍会经过平台现有安全校验。
7. 补充封面和资料，确认后再发布。

## 权限与隐私

- GitHub 登录和仓库导入是两套独立授权。
- GitHub App 只需要 Metadata 和 Contents 只读权限。
- 平台不会显示或保存 installation token。
- 私有仓库可用于建立草稿，但仓库地址不会出现在公开作品资料中。
- 你可以在平台断开连接，也可以在 GitHub 中撤销 App 或移除某个仓库。
- 撤销后平台不再读取仓库；既有作品和必要来源审计不会被偷偷改写。

## 许可证提示

自动识别的 SPDX 标识只是证据，不是法律意见。没有许可证、许可证无法识别、素材来源不清或多许可证冲突时，请先确认你拥有发布和再分发权。G1 不会因为检测到许可证就自动公开作品。

## Web ZIP 要求

- 上传构建后的静态文件，不要上传源码仓库本身。
- `index.html` 位于 ZIP 根目录。
- JS、CSS、图片、模型、WASM 等资源使用相对路径并包含在 ZIP 内。
- 当前流程不依赖仓库构建脚本，也不会读取 GitHub Actions 的产物。
- 大型网页 3D 项目仍受平台压缩包、解压后体积、单文件和文件数量上限约束。

如果 GitHub 导入暂未开放，可以继续使用“新建作品”并手动填写公开仓库与许可证；上传发布能力不受影响。
