# 墨鱼全局助手与平台 Agent

网页和独立桌面端共享应用外层的聊天工作区。主内容在左侧，助手在右侧；可收起、用鼠标或方向键调整宽度。手机使用底部面板，保留题目摘要，适配可视视口与软键盘。界面沿用墨鱼主题变量，支持浅色、深色和高对比度。

## 会话和上下文

- 对话、草稿、侧栏开关和宽度按登录账户隔离，保存在当前标签页的 sessionStorage；刷新可恢复，关闭标签页后不承诺保留。第一期没有跨设备云端聊天记录。
- 切页面不清空对话或取消请求；历史问答保留题号，延迟回复继续归属发送时的题目。
- 默认跟随当前题目，可固定某题跨页面讨论；刷新后恢复为跟随模式，避免继续使用过期快照。
- 停止等待不会承诺取消已经到达模型服务的调用；失败不自动重发。新对话清空当前会话，其他账户不会继承这份会话。
- 已接通题目辅导、游戏与工具搜索、详情、打开及个人练习数据查询。可运行的公开作品进入播放器，其余作品进入详情；官方工具和内置课件进入各自工作区。打开回执仅证明界面导航，不代表已玩完、学习完成或工具任务执行完毕。论文仍从公开注册表排除，生产四个论文开关继续为 false。
- 后续消息可通过历史请求编号引用本账户真实的服务端工具回执；最多恢复最近三份，仍受实例内 10 分钟保留限制。前端卡片内容不作为服务端事实输入，其他账户不能通过伪造请求编号取得数据。

## 独立入口的模型配置

设置 `PLATFORM_ASSISTANT_ENABLED=true`，并在 API 服务端提供 `DEEPSEEK_API_KEY`。`PLATFORM_ASSISTANT_MODEL` 默认 `deepseek-chat`，可配置现有账户可用模型。密钥不进入浏览器、会话或工具上下文。未配置时显示明确的不可用状态，不生成模拟回答。

通过已有服务端 DeepSeek 适配器调用；每次模型调用输出上限 1200 token，调用超时 35 秒，每用户单个在途请求、每分钟最多 10 条新消息、全局最多 24 个在途请求。请求编号在单 API 实例内去重 10 分钟；多副本之间不共享去重和限流状态，扩容前需迁移到共享存储。

鉴权接口：`GET /v1/me/assistant/capabilities`、`POST /v1/me/assistant/messages`、`POST /v1/me/agent/tools`、`GET /v1/me/learning/insights`。发送只接受文字、受限历史与题目标识；服务端通过当前用户的练习服务重新读取题目和作答，未判题的标准答案和解析不会被附加到模型上下文。助手没有提交、改成绩或写入练习的权限。模型提示与解释属于学习辅助，正确性以原有核验和判题流程为准。

平台模型仍使用独立的结构化 JSON 协议，避免改变现有研究 Agent 的提供商适配器。每次模型输出只能是回复或一个工具请求，由服务端校验名称和参数后执行真实业务服务。工具白名单为 `search_capabilities`、`get_capability`、`open_capability`、`get_my_learning_data`；最多四次调用、一个打开动作，总模型等待预算 65 秒，客户端 80 秒。搜索结果和工具回执始终作为不可信数据处理。只有当前消息明确表达打开意图才会自动请求导航；其他情况保留结果卡片，由用户点击打开。前端再次从服务端解析稳定 ID，验证站内路由，并在路由实际切换后显示回执；停止等待、切换账户或新对话不会执行旧响应中的导航。

## 学习数据口径

`/learn/insights` 是网页、桌面和插件共用的数据页。支持学习概览、练习历史、错题，以及 7/30/90/365 天或全部时间，另可按学科、学段、知识点、难度筛选。筛选 ID 延续现有 taxonomy，不将小学、大学或其他学科误报为已经有题库。

统计由 PostgreSQL 在单条语句的一致快照中计算，覆盖全部匹配记录，不受旧历史 50 批或错题 100 条上限影响。正确率分母是已提交练习的已作答题数，未作答单列、不会记入错题；进行中练习单独计数。零样本的正确率为 null，不推断掌握程度。时间按滚动天数计算：已提交批次以提交时间、其他批次以创建时间筛选，响应带 since/asOf。历史及错题每页最多 20 条，offset 上限 1000，并返回 hasMore；汇总不截断。这里不包含课件、游戏学习进度，也不把游玩时间或未经验证的客户端计时当成学习时长。新增查询复用现有表，不修改历史迁移。

桌面通过固定业务 IPC 白名单调用同一套接口，令牌和刷新留在主进程。只有助手发送允许较长等待，普通业务期限不变，取消及账户切换继续阻断旧请求结果。

## 插件入口

Codex / MCP Apps 不渲染墨鱼聊天组件，也不调用墨鱼模型接口。界面通过 MCP Apps `ui/update-model-context` 同步当前题目，通过 `ui/message` 将用户点击的提示或讲解请求交给宿主聊天；外层 widget 验证子页面来源，回执验证父窗口及请求编号。

公开 MCP 增加 `get_my_learning_data`：返回带筛选条件的学习数据界面，不直接返回私有数据。已登录侧栏通过鉴权接口读取当前账户数据，再使用同一份受限校验器向当前宿主会话同步 `mooyuLearning`；该公开工具的导航响应不代表已经取得学习数据。数据页披露摘要共享行为；退出、切换账户或离开页面会清空本页上下文。最多共享 60 个统计分组或 10 条明细，截断时显式标记，内容不含凭据和账户标识。宿主不支持消息时提供复制摘要；不以平台模型替代宿主。未登录、没有数据或服务失败均明确展示，不生成假数据。

Harness 通过插件注册时绑定的 session scope 调用宿主的 `sessions.scope(sessionId).conversation.send(prompt)`，不查询或猜测全局当前会话。切题不会自动发送消息触发 Agent；点击提问时附上当时的题目快照。聊天服务在点击时检测，旧版宿主缺少接口时仍可打开平台并复制题目，不会因为新增聊天服务依赖而阻断整个插件。其他宿主通过 `host.assistant.send` 适配；不支持消息接口时提供复制题目上下文的明确退路，不会偷偷启用另一套聊天。

宿主接口参考：[Harness conversation service](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-conversation/src/client/service.ts)。本地当前 Harness 安装的部分链接已失效，因此本轮以真实浏览器桥接回归、桌面 IPC 验收和四端构建为准；安装后的实际宿主点击验收仍需在可用宿主环境补做。

## 本分支的发布边界

本次交付功能源码和验证结果，未更新线上服务或分发版本。仓库现有 preview.7 / 0.4.1 / 0.1.29 清单及统一归档仍指向上一轮发布。发布此功能前需固定新源码提交、提升版本，重新制作桌面及插件分发包，并执行对应安装升级验收；不要复用旧归档宣称客户端已包含新能力。本轮模型、登录采用隔离夹具，不调用收费提供商，也不使用正式账号。
