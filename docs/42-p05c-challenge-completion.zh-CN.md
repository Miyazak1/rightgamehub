# P0.5-C：挑战完成闭环

日期：2026-09-29。范围：猜百科一对一异步挑战的接收、结算、通知和历史记录；仍不包含私信、自由发帖或群聊。

## 用户闭环

完成今日猜百科 → 发起并复制挑战链接 → 另一名玩家接收 → 完成同日同题 → 系统自动比较成绩 → 双方看到胜负，发起者收到通知 → 休息室保留挑战记录。

成绩按“提示次数、猜测字符数、用时”依次从低到高比较。接收和结算均为幂等操作，一个链接只允许一名对手接收。

## 实现

- `0023_challenge_completion.sql` 增加挑战参与、完成结果和挑战完成通知；
- 每位玩家每天最多发起 5 个、接受 10 个挑战，并使用事务锁避免并发绕过限制；
- 新增接收、完成、我的挑战历史 API，契约与共享客户端同步生成；
- 挑战通关后自动结算，结果弹窗展示双方结构化成绩；
- 休息室增加挑战完成通知和挑战记录，可继续未完成的挑战；
- Harness 包升级到 `0.0.55`，VS Code/Cursor 扩展升级到 `0.2.2`。
