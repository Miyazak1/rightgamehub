# P0.6：轻量留存层

日期：2026-09-29。范围：连续参与、像素徽章和通知偏好。所有状态均由真实游戏与挑战行为推导，不增加签到任务、积分商城或无限信息流。

## 用户能力

- 休息室玩家卡片显示当前连续天数、最长连续记录与累计参与日；
- 自动解锁五枚轻量徽章：初次休息、三日火花、七日像素、挑战者、胜负手；
- 可分别开启或关闭关注、成绩回应、挑战结果三类站内通知；
- 关闭某类通知后，历史列表不再展示该类通知，后续也不再创建该类通知记录。

## 数据与接口

- `0024_retention_preferences.sql` 保存用户通知偏好；
- 连续参与与徽章从 `guess_baike_results` 和已完成挑战实时推导，没有可伪造的手动签到表；
- 新增留存摘要、读取通知偏好和更新通知偏好接口；
- 共享 API 客户端、OpenAPI 与 TypeScript 声明同步更新。
