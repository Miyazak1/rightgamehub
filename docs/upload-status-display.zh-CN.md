# 上传处理进度与发布结果

上传任务的 `state=succeeded` 只表示检查完成。界面通过同一个纯函数 `uploadDisplay` 与共享组件，结合 `publicationOutcome` 呈现真实上传和演示页：

| API 结果 | 展示 |
| --- | --- |
| succeeded + published | 八个阶段全部完成，最后显示“已发布” |
| succeeded + draft | 当前停在“可发布”，说明保留草稿、尚未发布 |
| succeeded + skipped_newer_intent | 停在“可发布”，说明更新的发布操作导致本次跳过、未替换线上版本 |
| succeeded + blocked | 停在“可发布”，说明作品或目标平台已暂停，未自动发布 |
| succeeded + pending/未知结果 | 显示检查完成，但发布结果未确认 |
| failed / expired / review_required | 显示失败、过期或待审核；不推断已完成阶段，也不标记已发布 |

阶段采用中性名称；已完成阶段显示勾号和完成标记。窄侧栏以两行完整展示八个阶段及文字，不再裁掉最后一步。

恢复任务时直接使用服务端结果；切换作品时清除旧展示，停止旧请求，恢复 Windows 任务时显示对应目标平台。刷新恢复仍使用原有会话内上传任务标识，不改变服务端发布行为。

验收包含纯状态单测及真实共享客户端的浏览器测试：文件传输到自动发布、API 终态恢复、草稿/跳过/受限、处理中、失败/审核/过期、演示一致性及 320/360px 布局。

无新增数据库迁移。VS Code/Cursor 0.3.42，Harness 0.1.24。
