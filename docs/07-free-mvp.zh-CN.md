# 免费首版：软件内上传、下载与游玩

更新：2026-09-22 · **当前实施基线** · [目录](./README.md)

本篇规定免费首版的业务范围；本次新增的三宿主完整客户端和 Windows 安装包分发以 [18](./18-multi-host-client-spec.zh-CN.md)、[19](./19-windows-package-spec.zh-CN.md)为准，配合 [13 技术设计总纲](./13-technical-design.zh-CN.md)及 14—17 实施。

## 1. 本轮决定

首版建设免费的网页作品托管和 Windows 发布包分发平台。用户在 Harness、VS Code 或 Cursor 编辑器内上传已构建的小游戏、网页 3D、创意项目或 Windows 包，通过检查后发布。当前不开发收费功能，包括价格设置、订单、支付沙箱、购买权益、退款、佣金、作者收款入驻和结算。

海外首发、中国大陆公司经营、平台提供托管、两种 agent 入口的方向保持不变。此前交易与结算文档留作后续参考，不再作为免费首版的开发任务或上线依赖。

**Windows 作品补充**：首版明确包含便携 ZIP、独立 EXE 和 EXE 安装包的上传、检测、下载与管理，见 19。EXE 在功能区游玩按 [独立验证计划](./09-exe-sidebar-validation.zh-CN.md)继续实测，尚未证明；下载成功与独立窗口启动不能算作侧栏游玩通过。网页闭环与 Windows 分发可先开发，原生运行实验并行。

## 2. 最短使用流程

**作者在宿主功能区：登录 → 选择网页或 Windows 包 → 填写作品名称 → 上传检查与发布 → 获得链接。** 名称可从文件名预填，封面、介绍和分类之后补充。上传按钮明确写“上传并发布”，也可选私有草稿；更新与撤下同样在插件内完成，不要求另开作者网站。

**玩家在宿主功能区：浏览作品 → 网页点击开始，或 Windows 点击下载 → 游玩或查看下载管理。** 公开作品无需注册、领取或加入作品库。需要声音、全屏或指针锁时由玩家主动触发；系统文件选择/保存对话框允许使用。未验证原生侧栏能力前不展示可用的 EXE“功能区运行”按钮。

“上传即玩”指合格包处理完成后自动可用，不是跳过文件检查，也不是保证上传字节完成的瞬间就能运行。页面显示上传、检查、就绪或失败；失败给出可操作原因。服务器生成链接不代表游戏逻辑本身没有 bug。

宿主接入和验收以 18 为准：Harness bundle 与 VS Code/Cursor VSIX 共享平台界面和契约；网站及内置浏览器保留分享和回退用途，不能替代三宿主内的完整闭环验收。免费模式不自动证明插件目录允许上架，先交付独立测试安装包。

## 4. 支持什么上传包

网页 ZIP 根目录包含 `index.html`，其余 HTML/CSS/JS、WASM、图片、模型和音频使用相对路径，依赖尽量打包。Windows 包按 19 的独立规则接收，不要求 HTML 入口，不进入网页解包发布分支；上传桌面程序不会自动将其转为在线应用。

网页建议上限：压缩包 100 MiB、展开 300 MiB、文件 5,000 个、单文件 100 MiB。初期建议每作者 5 件作品、每个构建目标保留 3 个常规版本，按实测调整。Windows 配额见 19，不能套用网页单文件限制。网页样本优先 HTML/Canvas、Three.js/WebGL2 及已验证配置的引擎导出。

`platform.json` 可选，缺省使用最小运行权限；特殊外网连接、摄像头等权限不能通过上传 manifest 自行获得。缺少入口、路径错误、未打包依赖等情况给出明确错误，不能显示“发布成功”却只返回空白页。

## 5. 自动发布流水线

以下为网页分支；Windows 发布包进入 19 规定的独立扫描分支，两者按构建目标维护发布指针。

```text
上传到私有隔离区
  → 受限任务校验实际大小、哈希与 ZIP 结构
  → 安全解包，检查入口、规范路径、资源类型与默认权限
  → 通过：生成不可变版本，原子切换发布指针，返回分享链接
  → 不通过：说明错误；异常权限或风险信号进入复核队列
```

默认策略允许已开通发布权限的作者自动发布合格包。初期建议邀请作者以控制规模；平台不为每件正常作品安排必经的人工试玩。首页精选可以独立人工挑选，作品不进入首页也能通过链接体验。

单机上仅由受限制的处理进程解析文件，不执行上传的 JavaScript、WASM、构建脚本或服务器代码。任务建议一次处理一个包，设置内存、展开字节、临时目录和超时限制；拒绝路径穿越、绝对路径、链接和重复规范路径，不能用作者文件名直接拼存储路径。

需要执行作品的动态检查放在隔离环境中，作为异常复核和兼容性抽测；不在业务机启动未知游戏。静态检查不能证明所有脚本安全，因此保留不同可注册域名、按版本 origin、受限 iframe、CSP、外连限制和禁用能力。首次公开投稿前按真实攻击样本检查上传限流、举报和隔离效果。

## 6. 免费资产如何访问

原始上传包和草稿私有；已发布网页资产允许游客读取；作者业务仍要求认证。网页原始 ZIP 不自动提供整包下载，也不要求离线缓存。Windows 发布包通过专门检测后，经下载网关向游客提供；源桶、隔离区和草稿保持私有。

运行网关检查版本是否已发布、是否撤下及配额限制，之后返回缓存或对象存储资源，不查询购买权益、不创建免费订单、不签发付费资产能力令牌。物理存储桶仍可私有，只允许网关暴露已发布目录，避免草稿意外公开。

作品链接采用稳定 work ID，指向当前允许访问的版本；发布失败不覆盖旧版本。撤下后网关阻止新请求并失效缓存；已传送到用户设备的资源不能追回。

## 7. 最小部署与数据

网页基础服务沿用 [S 档配置](./06-server-sizing.zh-CN.md)：2 vCPU/4 GB、API/PostgreSQL 同机、对象存储与边缘网关。此前约 30—40 USD/月仅为网页低用量预算，未重新报价；新增邮件、Windows 扫描隔离资源和大文件分发单独核算，见 17、19，不能据此承诺完整首版总价。

首版数据实体以 14、18、19 为准，增加设备授权、上传 grant、WorkTarget、DownloadArtifact、ScanReport 与本地下载记录。订单、价格、卖方账户、购买权益和财务账本不建表，不安装支付 SDK。

最少 API 包括插件内认证、上传发布、自己的作品、目录、网页启动、Windows 下载元信息/字节流、按目标更新与撤下、举报及禁用。无需购物车、结账、领取、结算或订单接口。

## 8. 实施顺序与验收

| 步骤 | 交付 | 验收 |
| --- | --- | --- |
| 0. 三宿主客户端入口 | Harness bundle 与 VSIX、共享页面、受限 HostAdapter | 干净环境可安装；右侧位置、选文件与保存能力按宿主验证 |
| 1. 真实托管链路 | 上传、处理、稳定链接、隔离运行 | 作者 A 上传，未登录用户 B 能运行 2D、3D 和创意工具三份独立样本 |
| 2. 作者管理 | 登录、归属权限、更新、撤下 | A 不能编辑 B 的作品；失败更新不影响已发布版 |
| 3. 自动处理与故障提示 | 限额、队列、重试、异常复核 | 正常包无人工步骤；错误包显示原因；重复回调不重复发布 |
| 4. 小范围试运行 | 举报、禁用、日志、备份和恢复 | 私有草稿不能访问；恶意 ZIP 被拒绝；作品不能读平台登录态；能从备份恢复 |
| 5. Windows 分发闭环 | 三类包、独立扫描、续传、校验和下载管理 | 三宿主内完成操作；安装包保留原字节；失败扫描不公开 |

完整验收执行 17—19 的矩阵，必须覆盖三宿主作者和玩家交叉使用。原生 EXE 功能区运行单列实验记录；未通过不能记作全部游玩能力完成。播放器无价格/购买入口，未登录玩家无需领取，没有支付环境变量也能运行完整发布流程。

本轮衡量上传成功率、处理耗时、启动成功率、分享后真实体验、作者再次发布与资源成本。是否收费根据这些结果以后决定，不把收款渠道选择留在当前关键路径上。

本文调整的是方案，当前仓库的上传平台、自动发布和网页 3D 验收仍待实现。
