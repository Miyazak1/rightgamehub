Quiz Runner

A single-file, offline-friendly tool for running community quiz competitions — fair question order, a live timer and bell, automatic scoring, tiebreakers, and shareable results.

Which one do I need?

  • Never used this before? Start with the sample quiz to see how a round plays out.
  • Running a real event? Use Build your own quiz to make your quiz file, then open that file on the night.
  • Already ran a quiz and want to share the outcome? Go to View past results.

Past quizzes

Events that have been run with Quiz Runner.

To add yours: open a pull request on GitHub. Drop your files in the repo and add an entry to results/manifest.json:
 ·  Results link — put your snapshot JSON in results/ and set "file".
 ·  Play link — put your quiz HTML in examples/ and set "playUrl".
Both fields are optional; include whichever you have.
